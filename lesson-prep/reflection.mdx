## Reflection Q&A Person 2

<AccordionGroup>
    <Accordion title="How would you assess your learning progress: Why do you think you achieved the learning objectives in the module program?">
    I would asses it as successful, because I have learned a lot about React Native and how to use it to create a mobile app. Also we both have learned a lot about didactics and how to prepare a lesson (i.e. using the AVIVA model, as required/suggested in the learning objectives).
    </Accordion>
    <Accordion title="How did creating an app help you acquire the necessary knowledge?">
    Creating an app helped me acquire the necessary knowledge because it required me to apply the concepts and techniques I learned (from the React Native Reusables documentation, the Expo Go documentation, and the React Native documentation) in a practical way. It also helped me understand how to structure a React Native project and how to use different components and libraries to create a functional app.
    </Accordion>
    <Accordion title="What insights did you gain regarding lesson planning?">
    I gained insights regarding lesson planning, such as the importance of structuring a lesson using a model like AVIVA, which helps ensure that the lesson is engaging and effective, but also interesting for the audience/class. I also learned about the importance of considering the needs and interests of the learners when planning a lesson, and how to use different teaching methods and materials to engage them.
    </Accordion>
    <Accordion title="How could you apply the ideas from your lesson preparation to future training sessions or presentations?">
    I believe that the concepts I learned from the lesson preparation could be valuable for future training sessions or presentations, since they provide a structured approach to lesson planning that I believe can help me create more engaging and effective lessons and presentations when the time comes.
    </Accordion>
    <Accordion title="What, specifically, was your contribution to the learning product?">
        I've developed the React Native V-App template and the main app with the help of my other team partner.
    </Accordion>
    <Accordion title="What added value did your contribution bring to the team?">
        I believe that my contribution brought a major part of the learning objectives related to React Native and Expo Go, since it was a requirement to create a React Native app, and I was responsible for creating the app and making sure it worked properly.
