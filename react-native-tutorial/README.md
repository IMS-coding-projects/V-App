# V-App Template

This is the Template for the React Native Tutorial.

This Template is `npx @react-native-reusables/cli@latest init -t minimal-uniwind` but without the default placeholders. Also all [react-native-reusable components](https://reactnativereusables.com/docs/components/accordion) are included (`npx @react-native-reusables/cli@latest add --all`).

## How to run

1. Make sure (`git status`) you are on the template branch (`git checkout template`)
2. `npm i`
3. `npm run dev`
4. Open Expo Go on your mobile device/simulator and scan the QR Code.

> [!NOTE]
> You can format the codebase with `npm run format` (which runs prettier under the hood)
